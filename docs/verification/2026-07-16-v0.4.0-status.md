## Parity Boundary

The v0.3.0 token-saving decisions are retained for `search`, one-card
disclosure, bounded `run` previews, and explicit `log` retrieval. Functional
parity is not complete:

- MCP command execution is blocked after discovery.
- LM Studio `call_worker` is absent.
- Obsidian/filesystem read, list, and write capabilities are absent.
- MQTT and the broader planned adapter cards are absent.
- Cancellation is omitted while runs remain synchronous.

Raw `/execute`, unrestricted filesystem endpoints, and direct MQTT routes were
removed intentionally and should not be restored. Outcome parity should be
implemented through bounded command cards and the shared policy boundary.
